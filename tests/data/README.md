# Sample modules for testing and demonstration

Realistic, fully-formed Python modules used by the test-suite and referenced
from the documentation. Each pair is an **unsorted** input and its
**authoritative sorted** output, so tests can assert exact end-to-end behaviour
and docs can show genuine before/after examples.

| File pair                               | Strategy      | Highlights                                                                    |
| --------------------------------------- | ------------- | ----------------------------------------------------------------------------- |
| `web_service_{unsorted,sorted}.py`      | `stepdown`    | dataclasses, enums, stepdown function ordering, undersort on `Client`         |
| `csv_pipeline_{unsorted,sorted}.py`     | `stepdown`    | barriers (`_VALIDATORS` + `register_validator` calls), `TYPE_CHECKING`        |
| `cli_app_{unsorted,sorted}.py`          | `keep`        | the classic `app = typer.Typer()` barrier keeping decorated commands together |
| `plugin_registry_{unsorted,sorted}.py`  | `abstraction` | callee-first ordering: leaf utilities before the orchestrator                 |
| `inventory_models_{unsorted,sorted}.py` | `alpha`       | alpha on enums + functions, rich undersort (all visibility/type combos)       |

## Regenerating the sorted fixtures

Each `*_sorted.py` file is generated by sorting the matching `*_unsorted.py`
file with a **sample-specific config** (see the `SAMPLES` list in
`test_data.py` for the exact strategy used per sample). Re-run
`tests/test_data.py` (which asserts they match) or regenerate with:

```python
from pathlib import Path
from pyreorder import Config, sort_source

samples = [
    ("web_service", Config(strategies={"functions": "stepdown"})),
    ("csv_pipeline", Config(strategies={"functions": "stepdown"})),
    ("cli_app", Config(strategies={"functions": "stepdown"})),
    ("plugin_registry", Config(strategies={"functions": "abstraction"})),
    ("inventory_models", Config(strategies={"enums": "alpha", "functions": "alpha"})),
]
for name, cfg in samples:
    src = Path(f"tests/data/{name}_unsorted.py").read_text(encoding="utf-8")
    Path(f"tests/data/{name}_sorted.py").write_text(sort_source(src, cfg), encoding="utf-8")
```

Every `*_sorted.py` file is idempotent: running preorder on it again changes
nothing.
