# Onboarding — clean-sort

One-line project description: A clean, safe, deterministic Python import sorter with comment preservation and stepdown/abstraction sorting.

## Entry points

- **CLI**: `csort` (entry point in pyproject.toml)
- **Python API**: `clean_sort.run()`

## Build/test commands

- **Build**: `uv build`
- **Test**: `uv run pytest`
- **Lint**: `uv run ruff check`
- **Format**: `uv run ruff format`

## Tools

- **CodeGraph**: Available for code navigation
- **grepai**: Available for code search
- **repos**: Available for repository management
