# Contributing

Contributions are welcome. Development setup, the check and test tasks,
pre-commit hooks, the documentation build, and the release process are all
documented on the
[Development page](https://jr2804.github.io/pyreorder/development/).

- **Bugs and feature requests** — [issue tracker](https://github.com/jr2804/pyreorder/issues)
- **Pull requests** — fork, branch off `main`, and open a PR
- **Conduct** — this project follows the [Code of Conduct](CODE_OF_CONDUCT.md)
